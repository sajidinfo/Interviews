
## 🔥 Angular Interview Top Questions

### 🔹 Components / Templates

1. Difference between **Component** and **Directive**?
2. Agar hum `<app-login>hii</app-login>` likhe aur component me `<ng-content>` ho ya na ho, to output kya hoga? (jo humne abhi discuss kiya).
3. `ChangeDetectionStrategy.OnPush` kya hai, kyu use karte hain?
4. `trackBy` function `*ngFor` me kyu use karte hain? Without `trackBy` kya problem hoti hai?
5. Difference between **template-driven forms** and **reactive forms**?
6. Angular me `ViewChild` aur `ContentChild` me kya farq hai?
7. `ngOnInit` vs `constructor` – dono me difference kya hai?

---

### 🔹 Services / Dependency Injection

8. Service ko `NgModule` me add kiye bina use kar sakte hain kya? Agar haan, kaise?
9. Difference between **providedIn: 'root'** aur manually module me provide karna?
10. Lazy-loaded module me service scope kaise change hota hai?

---

### 🔹 RxJS & State

11. Difference between **Subject**, **BehaviorSubject**, and **ReplaySubject**?
12. `async pipe` kya karta hai?
13. `switchMap`, `mergeMap`, `concatMap`, `exhaustMap` ke use cases kya hain?

---

### 🔹 Performance

14. Angular app me **performance optimize** kaise karoge? (jitne points bata sakte ho)
15. Browser ke **Chrome DevTools Performance tab** kaise use karte ho? (jo tumne abhi pucha tha 👌)
16. Angular Universal (SSR) ka use kyu hota hai SEO me?

---

### 🔹 Security

17. XSS (Cross-Site Scripting) attack se Angular app ko kaise secure karoge?
18. Angular automatic CSRF protection kaise deta hai?
19. CORS kya hota hai, aur Angular/Node me ise kaise handle karte ho?

---

### 🔹 Routing

20. Lazy loading aur eager loading modules me difference kya hai?
21. Route guards ke types kya hote hain (`CanActivate`, `CanDeactivate`, etc.)?
22. Angular me **preloading strategies** kya hoti hain?

---

### 🔹 Testing

23. Angular component ko Jasmine/Karma se kaise test karte ho?
24. `TestBed` ka use kyu karte hain? Kab bina `TestBed` ke test likh sakte ho?
25. `beforeEach`, `it`, `expect` ka use interview style me samjhao.

---

### 🔹 Advanced / Misc

26. Angular lifecycle hooks ko order me explain karo (`ngOnInit`, `ngAfterViewInit`, etc.)
27. `ngZone` kya hai, aur kab manually use karte ho?
28. Angular me internationalization (i18n) kaise implement karte ho?
29. LTR/RTL (left-to-right / right-to-left) support Angular me kaise setup karoge?
30. Webpack aur Angular CLI ke beech kya relation hai?
